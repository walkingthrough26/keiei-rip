Editorial section opener: a vermilion mono kicker (+ optional number) over a Mincho heading underlined by an ink rule.

```jsx
<SectionLabel number="01" kicker="ARCHIVE" title="業種別の墓場" />
<SectionLabel kicker="OBITUARY" title="弔辞" align="center" onDark />
```

Set `onDark` when placed on a sumi band. Use one per major section to keep the page scannable.
