A figure-plaque: large mono number with a unit, an ink rule, and a Japanese label. For lifespan, store count, debt, etc.

```jsx
<StatPlaque value="33" unit="年" label="享年" sub="1976–2009" />
<StatPlaque value="217" unit="店" label="最盛期の店舗数" accent />
```

`accent` colors the number vermilion. Group 2–4 across a record band.
